# 반영 과목 검사 점검 — 2026-10-21, 2026-10-22 보완

대상: 상담.html에 등록된 47개 전형, 계열·예외를 포함한 70개 산출 기준.

## 수정 내용

- 전체 입력 성적을 먼저 검사하던 방식을 반영 기간 및 전형별 후보 범위를 먼저 확정하는 방식으로 변경.
- 교과·유형·지정 과목 기준에서 확실히 제외된 행은 계산에 필요한 성적 검사에서도 제외. 제외 사유는 상세 표에 유지.
- 상위 N과목, 사회/과학 선택, 가산·감점 대상은 최종 used에 없더라도 후보 또는 의존 항목이므로 검사 대상으로 유지.
- 감리교신학대: 후보 교과에서 2학점 이상, 수강자수 30명 이상 조건을 판정. 미기재 수강자수를 0명으로 간주하지 않음. 원점수 누락 후보가 있으면 최고 과목을 임의로 선정하지 않고 과목명과 누락값 표시.
- 성신여대: 반영 후보 과목의 수강자수 및 해당 성취도 분포가 없으면 과목명을 표시하고 계산 보류. 제외 교과 누락은 영향 없음.
- 반영 기간 밖(3-2) 과목의 성취도·등급 오류가 다른 학기 계산을 막지 않도록 수정. 학기 자체가 불명인 행은 포함 여부를 판단할 수 없어 확인 필요.
- 동덕여대: 필수 4개 교과 중 일부 누락 시 누락 교과를 0점으로 처리한 환산점수를 제시하지 않음.
- 서울한영대: 지정 과목명 비교에 Unicode/공백 정규화 적용.
- 예정 과목 검사 및 관심 전형별 예상 결과에도 각각의 전형 범위 적용.
- 비교표에서 계산 불가 사유를 직접 표시.

## 검증 범위와 미확인 사항

이 검사는 **프로그램의 전형별 반영 범위와 검사·계산 간 일관성 점검**이다. 기존 엔진과의 비교는 회귀 검사이며 대학 공식 산식의 정확성을 독립적으로 입증하지 않는다.

이번 점검에서 47개 전형의 공식 시행계획 원문 전체를 새로 대조하지는 않았다. 기존 데이터에 있는 진로선택 미구현, 한국사 포함 해석, 가중 방식 및 환산표 미공개 문제는 완료로 표시하지 않는다. 공식 자료가 없는 산식은 임의로 보충하지 않는다. 감리교신학대의 원점수 평균도 공식 환산점수가 아닌 참고값이다.
